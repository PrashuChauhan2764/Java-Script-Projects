Connect your Firebase project

This ledger is wired to run on Firebase Firestore, but it needs your own project's keys before it can save anything. This is a one-time setup — about 10 minutes.

  1. Go to console.firebase.google.com and create a new project (any name, e.g. "hisab-ledger").
  2. In the project, open Build → Firestore Database → Create database. Choose Start in test mode for now (open access — see note below).
  3. Click the gear icon → Project settings → scroll to "Your apps" → click the </> (Web) icon → register the app (any nickname).
  4. Firebase will show a firebaseConfig object. Copy it.
  5. Open this file's code, find the section marked PASTE YOUR FIREBASE CONFIG HERE near the top of the <script>, and paste your config in place of the placeholder values.
  6. Save the file and reopen it. That's it — every entry now saves to your own Firebase project, live, for anyone who opens this file or its hosted link.

Security note: "test mode" allows anyone to read/write your database with no login — that's what makes "anyone can enter data anytime" possible without accounts. Test-mode rules expire after 30 days; before then, replace them in Firestore → Rules with:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

This keeps it permanently open to anyone with the link — same trade-off as test mode, just without the 30-day expiry. If you ever want to restrict who can write, that needs adding Firebase Authentication, which I can help with separately.
