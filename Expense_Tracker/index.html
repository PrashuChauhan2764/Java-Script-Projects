Connect your Firebase project

This ledger is wired to run on Firebase Firestore, but it needs your own project's keys before it can save anything.

  1. Go to console.firebase.google.com and create a new project.
  2. Build → Firestore Database → Create database, start in test mode.
  3. Project settings → Your apps → </> Web → register the app.
  4. Copy the firebaseConfig object shown.
  5. Paste it into this file where it says PASTE YOUR FIREBASE CONFIG HERE.
  6. Save and reopen this file.
